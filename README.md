# GymPassJUST

مشروع لإدارة اشتراكات الجيم وحجز الحصص وتسجيل الحضور باستخدام QR. يحتوي على حسابات طالب ومدرب ومدير، وواجهة بالعربي والإنجليزي.

التقنيات: HTML وCSS وJavaScript، وخادم Node.js مع Express وقاعدة بيانات SQLite.

## تشغيل المشروع

1. ثبّت **Node.js 24** من [الموقع الرسمي](https://nodejs.org/en/download). المطلوب إصدار 24.10 أو أحدث ضمن سلسلة 24.
2. نزّل المشروع من **Code → Download ZIP** ثم فك الضغط بالكامل.
3. افتح المجلد الذي يحتوي على `package.json` واضغط مرتين على **Start-GymPass.cmd**.
4. انتظر رسالة الجاهزية ثم افتح [http://localhost:3000](http://localhost:3000).

يحتاج أول تشغيل إنترنت لتثبيت المكتبات. اترك نافذة التشغيل مفتوحة أثناء استخدام الموقع، واضغط **Ctrl+C** لإيقافه.

يمكن التشغيل من PowerShell داخل مجلد المشروع أيضاً:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd start
```

على macOS أو Linux استخدم `npm` بدلاً من `npm.cmd`.

لا تفتح `public/index.html` مباشرة؛ يجب تشغيل الخادم حتى تعمل الحسابات وقاعدة البيانات.

## مهم — اختار الحسابات حسب مكان تشغيل الموقع

> **حسابات الجهاز وحسابات الاستضافة منفصلة تماماً، حتى لو كان الإيميل نفسه.**
> إذا فتحت `http://localhost:3000` استخدم حسابات نسختك المحلية. وإذا فتحت `https://gympassjust.pages.dev` استخدم حسابات الاستضافة. تغيير كلمة المرور أو إنشاء حساب في واحدة لا يغيّر الأخرى.
> هذه حسابات للمشروع فقط، وليست حسابات جامعية رسمية.

### 1. حسابات التشغيل المحلي — على جهازكم

**للدكتور أو أي شخص ينزّل المشروع لأول مرة:**

1. شغّل `Start-GymPass.cmd` واترك نافذته مفتوحة حتى تظهر رسالة الجاهزية.
2. افتح [http://localhost:3000](http://localhost:3000).
3. داخل مجلد المشروع، افتح **`accounts/initial-accounts.md`**. يُنشأ هذا الملف تلقائياً عند أول تشغيل.
4. انسخ إيميل الحساب وكلمة مروره من هذا الملف، ثم سجّل الدخول بالدور الذي تريد تجربته.

> **مهم:** الإيميلات وكلمات المرور الخاصة بالتشغيل المحلي موجودة في ملف **`accounts/initial-accounts.md`** داخل مجلد المشروع بعد أول تشغيل. كل نسخة جديدة تولّد كلمات مرور خاصة بها؛ استخدموا الملف الموجود على جهازكم. إذا غيّرتم كلمة المرور لاحقاً، استخدموا الكلمة الجديدة.

| الحساب | الإيميل |
| --- | --- |
| طالب 1 | `student1@gympassjust.local` |
| طالب 2 | `student2@gympassjust.local` |
| المدرب | `coach@gympassjust.local` |
| المدير | `admin@gympassjust.local` |

يمكن إنشاء طالب جديد من صفحة **التسجيل**. المدير يستطيع إنشاء حسابات الموظفين من **إدارة الحسابات**. تغيير كلمة المرور من **حسابي**، وتبقى الكلمة الجديدة محفوظة عند إعادة التشغيل.

### 2. حسابات الموقع المستضاف — على الإنترنت

**رابط الموقع:** [https://gympassjust.pages.dev](https://gympassjust.pages.dev)

للتجربة على الإنترنت، افتح الرابط مباشرة ثم استخدم الإيميل وكلمة المرور الموجودين في **ملف حسابات الموقع المستضاف الذي يسلّمه لكم صاحب المشروع بشكل خاص**. هذا الملف منفصل عن ملف الحسابات المحلية، ولا يكون ضمن ملفات التنزيل من GitHub. لا تحتاج تشغيل `Start-GymPass.cmd` لاستخدام هذا الرابط.

| الحساب | الإيميل | الحصول على كلمة المرور |
| --- | --- | --- |
| طالب 1 | `student1@gympassjust.local` | من ملف حسابات الاستضافة الخاص |
| طالب 2 | `student2@gympassjust.local` | من ملف حسابات الاستضافة الخاص |
| المدرب | `coach@gympassjust.local` | من صاحب المشروع بشكل خاص |
| المدير | `admin@gympassjust.local` | من صاحب المشروع بشكل خاص |

> **مهم:** كلمات مرور الموقع المستضاف محفوظة في ملف خاص ولا تُنشر في هذا المستودع العام. احتفظ بملف حسابات الاستضافة لنفسك، ولا ترسل حساب المدير للزوار. حسابات ملف التشغيل المحلي لا تخص الموقع المستضاف.

يمكن للزائر إنشاء حساب طالب من صفحة **التسجيل**، والمدير يستطيع إنشاء حسابات مدربين إضافيين. عند تغيير كلمة المرور من **حسابي** تبقى الكلمة الجديدة محفوظة ولا تعيد الاستضافة تعيينها.

## تجربة المشروع

1. ادخل بحساب المدرب وأنشئ حصة بموعد مستقبلي. الحجز يفتح قبل الحصة بـ48 ساعة.
2. ادخل بحساب طالب، واشترك بباقة مناسبة ثم احجز الحصة. الدفع محاكاة داخل المشروع.
3. أثناء وقت الحصة، افتح بطاقة QR من حساب الطالب وسجّل الحضور من حساب المدرب. يمكنك نسخ نص الرمز ولصقه إذا كنت تستخدم جهازاً واحداً.

تبدأ النسخة الجديدة بأربعة حسابات وسبع باقات، دون حصص أو اشتراكات جاهزة. الحضور يحتاج اشتراكاً فعالاً وحجزاً مؤكداً في الحصة نفسها.

## ملفات المشروع

| الملف أو المجلد | وظيفته |
| --- | --- |
| `public` | صفحات الموقع والتنسيق وكود الواجهة والصور |
| `src` | الخادم والحسابات وقواعد الحجز وقاعدة البيانات |
| `package.json` | المكتبات وأوامر التشغيل والاختبار |
| `package-lock.json` | إصدارات المكتبات المطلوبة للتثبيت |
| `.npmrc` | إعدادات npm |
| `Start-GymPass.cmd` | تشغيل المشروع على Windows |
| `tests` | اختبارات المشروع المنسوخة من المصدر |

هذه النسخة مخصصة للتشغيل المحلي. إعدادات النشر على Cloudflare وDocker والتقارير غير مرفقة.

## الاختبارات

بعد تثبيت المكتبات:

```powershell
npm.cmd run check
npm.cmd test
```

يشغّل `npm test` اختبارات النسخة المحلية مع حد تغطية 70% من تعليمات الخادم. احتُفظ بملفي اختبارات Cloudflare من المشروع الأصلي داخل `tests`، لكنهما غير مشمولين بهذا الأمر لأنهما يحتاجان ملفات النشر والمكتبات الموجودة في المستودع الأصلي.

## حفظ البيانات وحلول التشغيل

يحفظ النظام بياناته في `data/gympass.db` ويُنشئ مجلدي `accounts` و`backups` أثناء التشغيل. احتفظ بهذه المجلدات عند نقل نسختك المحلية؛ لا تحتاج إعادة التثبيت في كل تشغيل.

| المشكلة | الحل |
| --- | --- |
| `node is not recognized` | ثبّت Node.js 24 وأعد فتح نافذة الأوامر. |
| لم يُعثر على `package.json` | افتح الأوامر داخل مجلد المشروع المستخرج. |
| PowerShell يمنع npm | استخدم `npm.cmd` أو ملف `Start-GymPass.cmd`. |
| المنفذ 3000 مستخدم | أوقف نافذة التشغيل القديمة بـCtrl+C ثم شغّل نسخة واحدة. |
| الموقع لا يفتح | تأكد أن نافذة الخادم مفتوحة وأن رسالة الجاهزية ظهرت. |
| ملف الحسابات غير موجود | شغّل الخادم أولاً ثم افتح مجلد `accounts` داخل المشروع. |
